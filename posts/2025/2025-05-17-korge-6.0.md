KorGE 6.0.0 has been released:

* This version supports off-screen rendering compatible with KorGE Forge IDE preview panel
* Splits all the libraries to their own and stabilises their ABI to be future-proof (ensured via plugin)
* Kotlin 2.0.20
* Minor tweaks to multiple APIs since 5.x
* Multiple fixes and improvements

Tried to get most of the things working, but sure there will be missing things that left for new contributors and maintainers. Just updated most of the starter kits, showcases and libraries from the store to be 6.0.0-compatible: https://store.korge.org/

With this version I'm leaving the project as explained [here](/leaving-and-looking-for-maintainers/) and I won't do any extra KorGE related commits. I will still help new maintainers to get started as required.

There is a new page documenting the current infrastructure:
https://docs.korge.org/infrastructure/
